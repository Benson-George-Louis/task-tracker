# 📝 Task Tracker

A simple task management web app. Users can sign up, log in, and manage their daily tasks.

---
## 🚀 Tech Stack

MERN (MongoDB, Express, React, Node.js) with JWT-based authentication.

---
## 🔮 Future Updates

These are optional features planned for future versions:

- Add **due dates** to tasks
- Introduce **categories or tags** for better organization
- Improve **responsive design** for mobile and tablet devices
